[CENTER][SIZE=6][B]EcoJobs[/B][/SIZE][/CENTER]
[CENTER][B]日常のサバイバル行動でお金が稼げる20種類のジョブプラグイン。レベル・プレステージ・GUI操作に完全対応。[/B][/CENTER]

単独動作のプラグインです(EcoTPは不要ですが、このシリーズの他プラグインと同様にVault経由で報酬を支払います)。Vault対応の経済プラグインであれば何でも連携できます。

[SIZE=5][B]主な特徴[/B][/SIZE]
[LIST]
[*][B]20種類のジョブ[/B] — 採掘工・穴掘り師・木こり・農家・建築士・漁師・お宝ハンター・ハンター・弓術師・討伐者・戦士・繁殖家・調教師・毛刈り師・養蜂家・魔道士・製錬工・職人・商人・探検家。それぞれ[I]config.yml[/I]で報酬表を自由に設定できます。同時に加入できるのは[I]max-concurrent-jobs[/I](デフォルト3個)まで。
[*][B]レベル・プレステージ[/B] — 経験値を得るとジョブのレベルが上がり(成長曲線は設定変更可)、レベルが上がるほど報酬も増えます。最大レベルに到達すると[I]/jobs prestige <ジョブ名>[/I]でレベル1に戻す代わりに永続的な追加報酬ボーナスが付き、サーバー全体に告知されます。
[*][B]レベルマイルストーン[/B] — どのジョブも、設定したレベル(デフォルト10・25・50・75・100)に到達すると一時ボーナスがもらえ、サーバー全体への告知と専用サウンドが流れます。プレステージで再度同じレベルを通過した際も再度発生します。
[*][B]不正防止のブロック追跡[/B] — ブロックを設置してすぐ壊しても、採掘工・穴掘り師・木こり、および農家の「背の高い植物」収穫では報酬が出ません。通常の農作物は対象外です(育つのに必ず実時間がかかるため)。
[*][B]ブースター・イベント機能[/B] — [I]/jobs booster start <ジョブ名|all> <お金倍率> <経験値倍率> <分数>[/I]で期間限定の報酬倍増イベントを開始できます。全体対象・特定ジョブ対象を組み合わせると倍率は掛け算で重なります。管理者GUIからもワンクリックで同じ操作が可能です。
[*][B]洗練されたGUI(チャット操作だけではありません)[/B] — [I]/jobs menu[/I]でハブ画面(自分のジョブ・ランキング・設定、スタッフ向けには管理者パネルへのショートカットも)が開きます。枠付きのジョブ一覧にはプレイヤーのサマリー表示と各ジョブの経験値プログレスバー、ランキング画面には実際のプレイヤーヘッドを表示、個人設定メニューではクリック音・獲得額のアクションバー表示のON/OFFを切り替えられます。
[*][B]管理者GUI[/B] — [I]/jobs admin[/I]から、config.ymlを一切編集せずに各ジョブの有効/無効切り替えや報酬倍率のリアルタイム調整ができ、コマンドと同じブースタークイック操作も使えます。
[*][B]MySQL・YAML両対応の保存先[/B] — 同じデータベースを指す複数サーバー間でジョブの進行状況を共有可能。設定不要のYAMLがデフォルトです。
[*][B]PlaceholderAPI対応[/B] — %ecojobs_level_<ジョブ名>%、%ecojobs_xp_<ジョブ名>%、%ecojobs_prestige_<ジョブ名>%、%ecojobs_joined_<ジョブ名>%、%ecojobs_total_level%、%ecojobs_top_<ジョブ名>_<順位>_name% など。
[*][B]完全対応の日英バイリンガル[/B] — メッセージはすべて[I]config.yml[/I]にまとまっており(デフォルトは英語、日本語版も同梱)、EcoTPと同じ[I]language: en/ja[/I]方式です。
[/LIST]

[SIZE=5][B]コマンド一覧[/B][/SIZE]
[CODE]/jobs join|leave|list|stats|top|menu|info|prestige <ジョブ名>
/jobs admin
/jobs booster start|stop|list
/jobs reload (エイリアス /job)[/CODE]

[SIZE=5][B]権限[/B][/SIZE]
[LIST]
[*]ecojobs.use(デフォルト: true) — ジョブへの加入/脱退/プレステージ、自分の統計の閲覧
[*]ecojobs.top(デフォルト: true) — ジョブランキングの閲覧
[*]ecojobs.bypass.maxjobs(デフォルト: false) — 同時加入数の上限を無視
[*]ecojobs.admin(デフォルト: op) — /jobs reload、/jobs admin、/jobs booster
[/LIST]

[SIZE=5][B]動作環境[/B][/SIZE]
[LIST]
[*]Paper 26.2以降(Paper専用 — 管理者GUIのアイテム発光演出と獲得額のアクションバー表示にPaper専用APIを使用しています)
[*][B]任意:[/B] Vault + EcoTP等の経済プラグイン(無くてもレベル・経験値は正常に機能しますが、お金は支払われません)
[*][B]任意:[/B] PlaceholderAPI(プレースホルダー用)
[/LIST]

[SIZE=5][B]設定[/B][/SIZE]
各ジョブの報酬表・レベル成長曲線・プレステージ/マイルストーンボーナス・同時加入数の上限・保存先(YAML/MySQL)、およびプレイヤー向けメッセージ(英語・日本語)はすべて[I]config.yml[/I]で設定できます。
