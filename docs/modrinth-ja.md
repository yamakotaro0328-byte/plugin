# EcoTP

**距離制の料金でテレポートする、単独動作の経済プラグイン。** Essentials など他の経済プラグインは不要です。EcoTPが自前で残高を管理しつつ、Vault(必須)経由でショップ等の他プラグインとも連携できます。

---

## 主な特徴

- **独立した経済システム** — 残高はEcoTP自身が保持します(デフォルトはYAML、複数サーバーで共有したい場合はMySQLも選択可)。Vaultは他プラグインとの連携のために必須です。
- **Essentialsからの残高引き継ぎ** — プレイヤーが初めて確認されたタイミングで、既存のEssentialsの残高を自動的に引き継ぎます。
- **距離制のテレポート料金** — `/home`・`/spawn`・`/warp`・`/tpa`・`/tphere`は実際の3次元距離に応じて課金されます: `max(最低料金, ceil(距離 ÷ ブロック単価))`。すべて設定変更可能です。
- **/tphere(着払い)** — 相手を自分のもとへ呼び出すコマンド。移動するのは相手なので、料金は相手が支払います。`/tpa`はその逆で、自分が移動し自分が支払います。
- **悪用防止のテレポート安全条件** — 敵対Mobが近くにいない・直近にPvPをしていない・数秒間動いていない(視点移動はOK)・同じディメンションにいる、を確認します。違反すると中断され、課金もされません。
- **複数の名前付きホーム** — `/sethome 名前`、`/home 名前`、`/delhome 名前`、一覧は`/homes`。
- **ワープ** — 管理者が`/setwarp <名前>`で全員共通のワープ地点を登録し、プレイヤーは`/warp <名前>`またはGUIメニューから移動できます。
- **柔軟な支払い承認** — チャットのクリックボタン、同じコマンドの再実行、`/accept`・`/ok`(統合版対応)のいずれでも承認できます。
- **GUIメニュー** — `/menu`(または自動配布されるメニューアイテムを右クリック)で、ホーム・スポーン・ワープ・tpa・所持金・送金・ランキング・デイリー・寄付・投票をクリックだけで操作できます。
- **デイリーボーナス** — `/daily`で24時間に1回報酬を受け取れ、連続ログイン日数に応じたボーナスも付きます。
- **お金アイテム** — `/ecoitem give`(管理者用)でお金をアイテムとして配布。ドロップ・トレード・チェスト保管ができ、右クリックでスタックごと換金できます。
- **/donate(寄付)** — 寄付としてお金を送ると全体にお礼メッセージが流れます。受け取る側は`/donatemessage <メッセージ>`で文言を変えられます。
- **投票報酬(別プラグイン不要)** — Votifierリスナーを内蔵し、v1(鍵方式)とNuVotifierのv2(トークン方式)の**両方**に対応。既存のNuVotifierも自動検出します。オフライン中の投票は次回ログイン時に付与され、投票サイトのリンクは`/menu`からクリックで開けます。
- **投票ランキング&累計ボーナス** — `/votetop`でランキングを表示。設定した累計回数(例: 10回・50回・100回)に達すると追加ボーナスが付与されます。
- **個人チャット** — `/msg <プレイヤー名> <メッセージ>`(エイリアス `/tell`・`/w`・`/pm`)と`/reply`(`/r`)。
- **放置(AFK)** — `/afk`または一定時間操作が無いと自動で放置状態に。タブリストに[AFK]表示、放置キック(任意)にも対応。
- **チャット整形(任意)** — 接頭辞(Vault経由でLuckPermsから取得)+名前+本文。別のチャット装飾プラグインの置き換え用です。
- **ローマ字→日本語変換(`/roma`)** — 自分のローマ字チャットを日本語(かな・漢字)へ自動変換するかを切り替えられます。
- **チャットURLの自動リンク化** — チャットに書かれたURLを、クライアント設定に関係なくクリックで開けるリンクにします。
- **内蔵Webダッシュボード(任意)** — ブラウザから残高を確認・変更できる軽量なWeb UI(デフォルト無効)。スタッフごとのログインにも対応。
- **細かくカスタマイズ可能** — 文言と通貨単位はすべて`messages.yml`(デフォルト英語、日本語版同梱)。各機能や独自経済そのもののオン/オフも個別に設定できます。
- **PlaceholderAPI対応** — `%ecotp_balance%`、`%ecotp_balance_formatted%`、`%ecotp_sethome_cost%`、`%ecotp_votes%`、`%ecotp_afk%`。

## 動作環境

- Paper/Spigot 26.2以降、Java 25
- 必須: Vault(他プラグインとの経済連携)
- 任意: PlaceholderAPI(プレースホルダー)
- 投票報酬は内蔵リスナー(v1・v2両対応)で単体動作 — NuVotifierが必要なのは既存の環境をそのまま使いたい場合のみです

---

## 設定

料金・テレポート安全条件・保存先(YAML/MySQL)・機能ごとのオン/オフ・独自経済のオン/オフ(`economy.enabled`をfalseにするとVault経由で外部の経済プラグインを利用)・投票報酬と投票サイトのリンク・放置(AFK)・Webダッシュボードは`config.yml`で、プレイヤー向けの文言と通貨単位は`messages.yml`で設定できます。
