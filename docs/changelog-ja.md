[SIZE=5][B]EcoTP 1.6.0 — ワープ・投票ランキング・個人チャット・放置(AFK)[/B][/SIZE]

[B]新機能[/B]
[LIST]
[*][B]ワープ[/B] — 管理者が[I]/setwarp <名前>[/I]・[I]/delwarp <名前>[/I]で全員共通のワープ地点を管理し、プレイヤーは[I]/warp <名前>[/I]([I]/warp[/I]だけで一覧)や[I]/menu[/I]の新しい「ワープ」から移動できます。料金は距離制で、確認・テレポート安全条件は[I]/spawn[/I]と同じです。
[*][B]/votetop[/B] — 投票回数を記録するようにし、上位の投票者と自分の累計投票数を表示します。
[*][B]累計投票ボーナス[/B] — 設定した累計回数(デフォルト10回・50回・100回)に達すると、通常の報酬に追加ボーナスが上乗せされ、全体に通知されます。[I]vote-reward.milestones[/I]で設定できます。
[*][B]/msg・/reply[/B] — 個人チャット(エイリアス /tell・/w・/pm・/r)。/replyは送った側・送られた側どちらからでも直前の相手に返信できます。
[*][B]放置(AFK)[/B] — [I]/afk[/I]、または[I]afk.auto-seconds[/I](デフォルト300秒)操作が無いと自動で放置状態に。タブリストに[AFK]表示、放置中の人に/msgすると送信者に通知、放置キック([I]afk.kick-seconds[/I]、対象外にする権限[I]ecotp.afk.kickexempt[/I])にも対応。
[*][B]チャット整形[/B](任意・デフォルト無効) — 接頭辞+名前+本文。別のチャット装飾プラグインの置き換え用です。
[*][B]/roma[/B] — 自分のチャットのローマ字→日本語自動変換を切り替えられます。
[*]新しいプレースホルダー: [I]%ecotp_votes%[/I]、[I]%ecotp_afk%[/I]。
[/LIST]

[B]修正[/B]
[LIST]
[*]オフライン中に複数のサイトで投票しても報酬が1回分しか付与されなかった不具合を修正(次回ログイン時に全部まとめて付与。既に保留中の投票も引き継がれます)。
[*]60秒以内に別々のサイトで投票すると、2つ目が「再送」とみなされて捨てられていた不具合を修正(再送判定をサイトごとに)。
[*]オフライン中に届いた投票がコンソールに記録されるようにしました。
[*]26.2のサーバーで「Unsupported API version 26.3」となりEcoTPが起動しなかった不具合を修正。
[*]他のチャットプラグインがメッセージを整形し直すと、チャット内リンクのクリックが効かなくなることがあった不具合を修正。
[/LIST]

[B]アップデート時の注意:[/B] config.ymlが生成されるのは新規導入時のみです。既存のサーバーで設定を変えたい場合は、同梱のconfig.ymlから[I]afk:[/I]セクションと[I]vote-reward.top-limit[/I]・[I]vote-reward.milestones[/I]をコピーしてください。累計投票ボーナスは[I]milestones[/I]を自分で追加するまで[B]無効[/B]のままです(それ以外は追加しなくても既定値で動作します)。
